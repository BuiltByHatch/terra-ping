# Gray Wolf Population Data

## Files

- `gray_wolf_population_current_us_states.csv` contains a current U.S. state-level snapshot for gray wolf population estimates.

## Source

- Source CSV: <https://gist.githubusercontent.com/rlvaugh/f927ee9759db4e0b742356a5f160d682/raw/28001b2bd4f75e633fd932f6470ed6bd07e541a8/gray_wolf_populations.csv>
- Source page: <https://gist.github.com/rlvaugh/f927ee9759db4e0b742356a5f160d682>
- Source note: "Data from each state's Dept. of Wildlife and Fisheries or Dept. of Natural Resources."

## Additional Historical Source

- International Wolf Center lower-48 historical trends page: <https://wolf.org/wolf-info/gray-wolf-population-trends-in-the-contiguous-united-states/>
- Coverage: estimated free-ranging gray wolf abundance in the contiguous U.S., 1963-2013.
- Caveat: the published page is a wide, sparse historical table with changing geographies over time, including state populations, regional recovery areas, Isle Royale, and shared Arizona/New Mexico Mexican wolf estimates.

## Caveats

- The CSV snapshot is community compiled, not a single official government dataset.
- Population estimates are minimum counts or modeled estimates depending on state and year; do not compare them as if every state used the same survey method.
- Arizona and New Mexico values should be treated carefully because Mexican wolf reporting is often a shared recovery-area population.
- Wisconsin's source CSV abbreviation is `WS`; this local normalized copy uses the correct postal abbreviation `WI` and notes that change.
