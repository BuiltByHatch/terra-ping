# TerraPing

Universal animal tracker for researchers, conservationists, and citizen scientists.

## Structure

```
├── code/           # Engineering packages
└── docs/           # Design, product, and research docs
```

## Getting Started

```bash
yarn install
yarn dev
```

## Packages

- [code/web](./code/web) - Main web application
- [code/universal-model](./code/universal-model) - Core data types and schemas
- [code/transformers](./code/transformers) - Data transformation layer
